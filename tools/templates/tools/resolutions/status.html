What this is checking

  • Sign-ons - proponent + 35 members for a bylaws amendment (Section 10.1); 25 for a project committee or campaign (Section 7.1). A general resolution needs no sign-ons - the Leadership Committee sets the agenda - so it shows n/a.
  • Deadline - filed ahead of the meeting (21 days for an amendment, 10 for a project committee) so the agenda can publish on time.
  • Where it lives - members read the text in Echo while it gathers sign-ons; once adopted it is archived with the chapter's passed resolutions.
  • Text locked - the wording hasn't changed since the first sign-on; any edit resets the count.
