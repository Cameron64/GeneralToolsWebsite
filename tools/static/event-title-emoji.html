Emoji that work in event titles

A short list, until the fix ships. Tap any emoji to copy it.

184 of the 3,944 standard emoji work in Echo's event fields right now. The ones that work are the older, simpler symbols. Newer full-color emoji fail, and they fail the whole event, not just the title.

This applies to the title, description and instructions fields alike. A fix is written and under review, so this list is temporary.
